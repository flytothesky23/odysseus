# v0.1.8-ko

This patch restores management reports to the traditional report style while preserving the wide-table readability fix from `v0.1.7-ko`.

## Highlights

- Keeps `경영분석` report introductions as normal narrative Markdown lists instead of large KPI cards.
- Removes management-only dashboard decoration such as ledger-grid backgrounds, card rails, strong colored table headers, and first-column highlight treatment.
- Preserves desktop width expansion and `.table-scroll` wrapping for wide route, KPI, and decision tables.
- Adds a regression assertion that the first management summary list remains a normal list.
- Verifies that CSS-only fake charts are not used for statistical chart generation.

## Verification

- `venv/bin/python -m py_compile src/visual_report.py src/deep_research.py`
- Targeted visual report, management category, and security regression tests.
- Playwright layout smoke for normal first-list display and wide-table horizontal scroll.

## Known Gaps

- Full Python test suite and Docker runtime were not rerun for this small visual regression patch.
- Automatic statistical chart generation is not included; it should be designed around structured data extraction rather than decorative report CSS.
