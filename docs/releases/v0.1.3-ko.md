# v0.1.3-ko

Odysseus Korean fork patch release for Deep Research artifact format selection and Obsidian-friendly exports.

This patch is for users who like the existing visual HTML Deep Research report but also want text-first archive files that can be stored in Obsidian or reused by another tool.

## Highlights

- Added result-format checkboxes to the Deep Research modal:
  - HTML
  - MD+JSON
- Kept HTML as the default so existing visual report workflows continue unchanged.
- Added Markdown export for completed research sessions:
  - `/api/research/report/{session_id}/markdown`
- Added structured session JSON export for completed research sessions:
  - `/api/research/report/{session_id}/session.json`
- Added completed-job actions that only show outputs selected for that research run:
  - `Visual Report`
  - `Markdown`
  - `JSON`
- Preserved artifact-format choices across queued, active, library, and result-peek research flows.
- Added owner-scope tests so Markdown/JSON export cannot be generated for another user's research.
- Extended Korean E2E smoke coverage for the result-format selector and the "at least one output" guard.

## Why This Matters

Deep Research now supports two complementary output styles:

- HTML for polished visual review and sharing.
- Markdown plus session JSON for Obsidian archiving, reproducible context, and later reprocessing.

The Markdown export includes Obsidian-oriented frontmatter and keeps sources/raw findings in a readable report structure. The JSON export includes research metadata, sources, raw findings, stats, and artifact URLs while excluding owner/token/secret fields.

## Install And Run

```bash
git clone https://github.com/flytothesky23/odysseus.git
cd odysseus
git checkout v0.1.3-ko
./start-macos.sh
```

Open:

```text
http://127.0.0.1:7860
```

## Notes For Existing Installs

- Restart the Odysseus server after upgrading.
- Refresh the browser so the Research modal loads the updated JavaScript.
- If no result format is selected, Odysseus falls back to HTML.
- The `MD+JSON` option exposes download buttons after a research job is complete.
- Search API keys, ChatGPT/Codex login tokens, `.env` secrets, and private auth files remain local machine setup and are not included in the release.
