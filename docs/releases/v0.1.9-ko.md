# v0.1.9-ko

This release migrates the Korean fork onto the rewritten upstream `dev` baseline at `d96c7af` while preserving the fork's Korean UX, Codex integrations, private knowledge workflows, and management-report contracts.

## Highlights

- Rebuilds the Korean fork on the current upstream architecture instead of merging the rewritten history into `v0.1.8-ko`.
- Preserves Korean onboarding, UI localization, macOS startup, and the Korean E2E contract.
- Restores the Codex CLI and Codexian loopback cookie bridge without widening OAuth or local-file trust boundaries.
- Supports the current ChatGPT Subscription catalog, including Codex 5.6 Sol, Terra, and Luna, with model-scoped reasoning choices.
- Restores Deep Research web/local/Obsidian combinations, Finder roots, JSON/YAML/CSV sources, HTML and MD+JSON exports, and management-analysis behavior.
- Keeps private-source failures off web fallback, excludes sensitive local files and symlink escapes, and preserves owner scope.
- Keeps management reports in a traditional document flow while retaining wide-table readability.
- Raises desktop sidebar navigation labels to a readable default without changing the mobile touch contract.
- Makes UNIX-socket and workspace-confinement tests portable across macOS temporary-path aliases.

## Private Data Migration

User data is intentionally not part of Git or this tag. When updating an existing installation:

1. Back up the current `.env` and `data/` before switching code.
2. Keep `data/app.db` and `data/.app_key` from the same snapshot.
3. Do not overwrite a target installation that already contains new sessions or settings.
4. Verify memory, email-account, provider-auth, session, and vector-store counts after startup.
5. Never copy tokens, passwords, cookies, OAuth JSON, or `.env` values into issues or logs.
