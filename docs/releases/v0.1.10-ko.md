# v0.1.10-ko

`v0.1.10-ko`는 `v0.1.9-ko` 이후 검증된 Odysseus 개발 기능을 하나의 재현 가능한 한국어 fork 릴리스로 고정합니다. 앱 자체의 upstream 버전은 `1.0.2`이며, `v0.1.10-ko`는 이 저장소의 한국어 통합 배포 버전입니다.

## 주요 변경

- Obsidian Vault Explorer에서 폴더 트리와 개별 노트를 선택하고, 제목·파일명·상대경로·frontmatter aliases를 먼저 색인합니다.
- 선택한 후보의 본문만 제한적으로 읽고, 같은 채팅의 follow-up에서는 고정된 근거와 변경분만 안전하게 재사용합니다.
- Kordoc `4.2.5` MCP로 PDF·Office·HWP 계열 문서를 읽기 전용으로 파싱하며 진행 상태·취소·timeout·실패 원인을 구분합니다.
- Korean Law MCP `4.9.2`에서 법령 검색 결과를 정확한 법령명과 MST로 좁힌 뒤 공식 조문을 재검증합니다.
- Contract Review 결과에서 로컬 문서, Vault 노트, 공식 법률, 모델 해석, 불확실성을 분리해 렌더링합니다.
- 모든 AI 응답의 명시적 저장 메뉴에서 Documents, 메모, Obsidian MD를 선택할 수 있습니다. 자동 저장은 하지 않습니다.
- Deep Research의 source-safe renderer, designed HTML, renderer gallery, session/model/reasoning/context budget 흐름을 포함합니다.
- Vault identity·owner scope·root-relative path·symlink escape·MCP server/tool identity를 각 실행 경계에서 fail-closed로 검증합니다.

## 새 기기에 설치

안정 릴리스를 그대로 설치하려면 태그를 지정해 clone합니다.

```bash
git clone --branch v0.1.10-ko --depth 1 https://github.com/flytothesky23/odysseus.git
cd odysseus
```

Docker 설치는 다음과 같이 시작합니다.

```bash
cp .env.example .env
docker compose up -d --build
```

macOS·Windows native 설치와 GPU 설정은 [setup guide](../setup.md)를 따르세요. 개인 `.env`, OAuth 자격, 세션, 문서, 벡터 데이터는 이 릴리스와 Git에 포함되지 않습니다.

## 기존 설치 업데이트

업데이트 전에 서비스를 종료하고 `.env`와 `data/`를 백업합니다. 특히 `data/app.db`와 `data/.app_key`는 반드시 같은 시점의 한 쌍으로 보관해야 합니다.

개발 브랜치를 최신 안정 릴리스 커밋으로 업데이트하려면 다음을 실행합니다.

```bash
git status --short
git fetch origin --tags
git switch dev
git pull --ff-only origin dev
git rev-parse HEAD
git rev-list -n 1 v0.1.10-ko
```

마지막 두 커밋이 같아야 합니다. 안정 태그에 고정된 detached checkout을 원하면 별도 설치 폴더에서 다음을 사용합니다.

```bash
git switch --detach v0.1.10-ko
```

코드 업데이트 과정에서 기존 `.env` 또는 `data/`를 삭제·교체하지 마세요. 대상 설치본에 이미 새 세션이나 설정이 있다면 다른 기기의 runtime data를 덮어쓰지 마세요.

## 검증하지 않은 외부 환경

- 비식별 fixture가 없어 실제 HWP/HWPX 파싱은 수행하지 않았습니다.
- 실제 이메일 송수신, OAuth refresh, 유료 모델 호출은 수행하지 않았습니다.
- Docker CLI가 없는 릴리스 Mac에서는 Docker Compose를 재실행하지 않았습니다.
- 최종 시각 검증은 Chromium 기반 headed browser에서 수행했으며 다른 브라우저는 재검증하지 않았습니다.

## 데이터 및 보안 경계

- `.env`, `data/`, API key, OAuth token, session cookie, 사용자 Vault 원문은 릴리스에 포함되지 않습니다.
- 보고서와 Obsidian 노트는 사용자가 명시적으로 저장 버튼을 누른 경우에만 생성됩니다.
- MCP inventory·runtime·identity 검증이 실패하면 일반 도구로 우회하지 않고 실패 상태를 표시합니다.
- 기존 `v0.1.9-ko` 태그는 이동하지 않았습니다.
