# v0.1.13-ko

> 이 릴리스는 `v0.1.14-ko`로 대체되었습니다. 기존 tag는 그대로 유지되며, 후속 한국어 문맥 복구·중복 인용 정규화·진화형 웹 지식 Documents·stale editor overwrite 방지는 새 릴리스를 사용하세요.

`v0.1.13-ko`는 `v0.1.12-ko`의 Contract Review Workspace와 개인화 데이터 계약을 유지하면서, 일반 채팅 웹검색을 실제 근거 조회 중심의 한국어 agentic search로 전환한 안정 릴리스입니다. 앱 자체의 upstream 버전은 `1.0.2`입니다.

## 핵심 변경

- 검색 후보, 실제 fetch 성공 근거, 최종 인용 근거를 서로 다른 상태로 관리합니다.
- 읽을 수 있는 본문과 stable source ID를 다음 Codex OAuth 모델 호출에 실제로 주입합니다.
- 비교·검증 질문은 검색 계획, 관련 공식 출처 선택, 본문 조회, 한국어 합성, 인용 검증을 거친 경우에만 완료합니다.
- 검색 도구의 `done`과 답변 완료를 분리하며, 빈 assistant 카드·내부 guard 코드·읽지 않은 source 노출을 제거합니다.
- 같은 근거 후속질문은 기존 evidence를 재사용하고, 새 사실이 필요할 때만 delta retrieval을 추가합니다.
- 검색 예산을 모두 사용한 경우에도 확보된 근거로 합성 단계로 전환하며, 정상 답변을 `Tool budget reached`로 끝내지 않습니다.
- 한국어 지시어·재시도·최신성·후속질문 문맥을 공통 의미 브리지로 처리합니다.
- 인라인 출처 링크와 코드가 포함된 Markdown 표를 안전한 HTML 표로 렌더링합니다.
- 기존 Vault Explorer, Contract Review, Kordoc, Korean Law, Deep Research, Documents, 세션·모델·reasoning·context budget·compaction·metrics 계약을 보존합니다.

## 새 기기에 설치

```bash
git clone --branch v0.1.13-ko --depth 1 https://github.com/flytothesky23/odysseus.git
cd odysseus
```

Docker 설치는 다음과 같이 시작합니다.

```bash
cp .env.example .env
docker compose up -d --build
```

macOS·Windows native 설치와 GPU 설정은 [setup guide](../setup.md)를 따르세요.

## 기존 설치 업데이트

서비스를 종료하고 `.env`와 `data/`를 먼저 백업하세요. `data/app.db`와 `data/.app_key`는 반드시 같은 시점의 한 쌍이어야 합니다.

```bash
git status --short
git fetch origin --tags
git switch dev
git pull --ff-only origin dev
git rev-parse HEAD
git rev-list -n 1 v0.1.13-ko
```

마지막 두 커밋이 같아야 합니다. 태그에 고정하려면 별도 설치 폴더에서 `git switch --detach v0.1.13-ko`를 사용하세요. 코드 업데이트 과정에서 기존 `.env`나 `data/`를 삭제·교체하지 마세요.

## 검증

- deterministic integration은 최종 모델 호출 messages에 stable source ID와 실제 fetched body가 포함되는지 검증했습니다.
- 실제 사용자 설치본의 기존 계정·Codex OAuth에서 공식 OpenAI Codex 소개와 GitHub `openai/codex` README를 fetch하고, 공통 기능 두 가지를 한국어로 합성해 각 주장에 클릭 가능한 인라인 출처를 연결했습니다.
- 같은 근거 follow-up은 새 검색 0회로 재사용했고, delta retrieval은 기존 두 출처를 유지하면서 새 공식 출처 하나만 추가했습니다.
- 실제 검색 취소, 재시도, 검색 예산 소진 뒤 근거 합성, 빈 카드·raw guard·상태 모순 0건을 확인했습니다.
- 실제 Codex OAuth 응답으로 출처 링크 두 개가 포함된 Markdown 표가 `<table>` 1개, 헤더 3개, 셀 6개로 렌더링되고 literal separator가 남지 않음을 확인했습니다.
- 전체 Python 테스트: `5107 passed, 3 skipped`.
- 변경 Python compile, 변경 JavaScript syntax, 정적 회귀, `git diff --check`를 통과했습니다.
- 검증 중 생성한 세션·메시지·fixture를 제거하고 기존 개인화 count와 DB/FTS/vector 일치를 복원했습니다.

## 검증하지 않은 외부 환경

- 실제 이메일 송수신과 OAuth refresh는 수행하지 않았습니다.
- 실제 사용자 Vault 원문 변경과 보고서 자동 저장은 수행하지 않았습니다.
- Chromium 이외의 브라우저에서는 최종 headed E2E를 재실행하지 않았습니다.
- Docker CLI가 없는 릴리스 Mac에서는 Docker Compose를 재실행하지 않았습니다.

## 데이터 및 릴리스 경계

- `.env`, `data/`, API key, OAuth token, session cookie, 사용자 질문·대화·검색 본문은 Git과 릴리스에 포함되지 않습니다.
- 기존 `v0.1.9-ko`부터 `v0.1.12-ko`까지의 태그는 이동하거나 삭제하지 않습니다.
- 검색 source는 실제 fetch에 성공한 근거만 노출하며, 보고서와 Obsidian 노트는 사용자가 명시적으로 저장한 경우에만 생성됩니다.
