# v0.1.2-ko

Odysseus Korean fork patch release for richer Deep Research private knowledge sources and Codexian session handoff.

## Highlights

- Expanded the Deep Research `Source` selector into six explicit modes.
- Added a macOS Finder folder picker for Deep Research knowledge sources.
- Added local structured-data support for JSON, YAML, and CSV files.
- Kept Obsidian and local-folder filtering distinct.
- Added Codexian session bridging from browser login/status into the Obsidian plugin configuration.
- Cleared the Codexian session bridge on logout or invalid browser-cookie status.

## Verification

- Python compile for research and bridge modules.
- `node --check static/js/research/panel.js && node --check scripts/e2e-ko-smoke.cjs`
- Targeted research owner-scope, auth, and Codexian bridge pytest slice.
- `ODYSSEUS_E2E_URL=http://127.0.0.1:7861 npm run e2e:ko`

## Known Gaps

- Full Python suite and Docker runtime were not rerun for this patch release.
- Finder folder picker is macOS-specific.
