# v0.1.2-ko

Odysseus Korean fork patch release for richer Deep Research private knowledge sources and Codexian session handoff.

This patch is for users who want Deep Research reports to combine web search, Obsidian notes, and selected local folders without requiring high-end local AI hardware or repeated manual session setup.

## Highlights

- Expanded the Deep Research `Source` selector into six explicit modes:
  - Web only
  - Local knowledge only
  - Web + Local knowledge
  - Obsidian only
  - Web + Obsidian
  - Web + Obsidian + Local folders
- Added a macOS Finder folder picker so local folders can become Deep Research knowledge sources from the Research modal.
- Added local structured-data support for JSON, YAML, and CSV files, converting them into searchable evidence text.
- Kept Obsidian and local-folder filtering distinct so `Obsidian only` does not silently include unrelated local folders.
- Added Codexian session bridging: browser login/status can sync the local `odysseus_session` cookie into the Codexian Obsidian plugin configuration.
- Cleared the Codexian session bridge on logout or invalid browser-cookie status so stale cookies do not linger.
- Extended Korean E2E smoke coverage for the Research source selector and knowledge-source row layout.

## Why This Matters

Deep Research can now work in three practical styles:

- External research: use the web search engine only.
- Private research: use Obsidian notes or user-selected local folders only.
- Hybrid research: combine web evidence with the user's own notes, JSON/YAML/CSV data, and project folders.

This lets a Korean user turn messy personal notes and local project data into polished HTML research reports while still keeping source boundaries explicit.

## Install And Run

```bash
git clone https://github.com/flytothesky23/odysseus.git
cd odysseus
git checkout v0.1.2-ko
./start-macos.sh
```

Open:

```text
http://127.0.0.1:7860
```

## Notes For Existing Installs

- Restart the Odysseus server after upgrading. If the browser shows `Not Found` when clicking Finder folder add, the front-end has loaded newer JavaScript than the running Python server.
- Refresh the browser after restart so the Research modal uses the updated JavaScript bundle.
- Local folder sources are stored in app settings as opaque `local:<id>` tokens.
- Search API keys, ChatGPT/Codex login tokens, and `.env` secrets remain local machine setup and are not included in the release.

## Known Gaps

- Full Python suite was not rerun for this patch release.
- Docker runtime was not revalidated for this patch release.
- The Finder folder picker is macOS-specific. Non-macOS environments should add folders through future server-side or settings-based alternatives.
- Users should choose narrow local folders. Hidden/system directories and known secret filenames are skipped, but broad folders may still contain private material that should not be indexed into reports.
