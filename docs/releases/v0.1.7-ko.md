# v0.1.7-ko

This patch makes Deep Research management reports fit operations-first Korean business data and keeps wide tables readable in the HTML visual report.

## Highlights

- Reframes `경영분석` as an operations-management report when the evidence is production, sales, logistics, route, byproduct, or field-operation data.
- Keeps corporate finance sections such as balance sheet, cash flow, operating profit, SG&A, purchasing, inventory, debt, and receivables conditional on explicit source evidence.
- Prevents reports from repeatedly generating "자료 없음" rows for corporate-finance categories when the user's source scope is intentionally operational.
- Adds management-report guidance for KPI boards, route/freight boards, variance boards, source reliability ledgers, and decision matrices.
- Wraps rendered markdown tables in `.table-scroll` so wide tables can scroll horizontally instead of compressing Korean text into one-character columns.
- Expands management report layout width on desktop and keeps mobile reports as a single column with horizontal table scroll.
- Adds KPI-card styling for the first management summary list.
- Updates management category and visual report tests for the new contract.

## Why

The `경영분석` label should not force a full corporate financial-statement template when the evidence is the user's real working dataset: production floor numbers, PSBall and byproduct sales, freight routes, and field management notes.

This patch treats that dataset as a first-class management-report source. It focuses the report on decisions the user can actually make from the available evidence and avoids undermining the report with repeated missing-finance caveats.
