# v0.1.11-ko

`v0.1.11-ko`는 `v0.1.10-ko`의 Contract Review Workspace와 검증된 한국어 통합 기능을 모두 포함하는 최종 패치 릴리스입니다. 실제 7860 수락 검증 중 발견한 PDF·email 문서의 불필요한 highlight.js 콘솔 오류를 제거했습니다. 앱 자체의 upstream 버전은 `1.0.2`입니다.

## 포함 기능

- Obsidian Vault Explorer의 폴더·노트 선택, metadata-first 검색, 제한된 후보 본문 조회.
- 같은 채팅의 고정 근거 follow-up, delta retrieval, stale identity·경로 escape 차단.
- Kordoc `4.2.5` MCP의 읽기 전용 문서 파싱과 진행·취소·timeout·실패 표시.
- Korean Law MCP `4.9.2`의 법령명·MST 확인 후 공식 조문 재검증.
- 로컬 문서·Vault·공식 법률·모델 해석·불확실성을 분리한 Contract Review renderer.
- AI 응답을 Documents·메모·Obsidian MD로 명시적으로 저장하는 공통 메뉴.
- Deep Research source-safe renderer, designed HTML, renderer gallery와 기존 세션·모델·reasoning·context budget 계약.
- PDF·email처럼 highlight.js grammar가 아닌 문서 형식은 코드 highlighting을 건너뛰는 console-safe guard.

세부 기능과 안전 경계는 [`v0.1.10-ko` 릴리스 노트](v0.1.10-ko.md)에 정리되어 있습니다.

## 새 기기에 설치

```bash
git clone --branch v0.1.11-ko --depth 1 https://github.com/flytothesky23/odysseus.git
cd odysseus
```

Docker 설치는 다음과 같이 시작합니다.

```bash
cp .env.example .env
docker compose up -d --build
```

macOS·Windows native 설치와 GPU 설정은 [setup guide](../setup.md)를 따르세요.

## 기존 설치 업데이트

먼저 서비스를 종료하고 `.env`와 `data/`를 백업하세요. `data/app.db`와 `data/.app_key`는 반드시 같은 시점의 한 쌍이어야 합니다.

```bash
git status --short
git fetch origin --tags
git switch dev
git pull --ff-only origin dev
git rev-parse HEAD
git rev-list -n 1 v0.1.11-ko
```

마지막 두 커밋이 같아야 합니다. 태그에 고정하려면 별도 설치 폴더에서 `git switch --detach v0.1.11-ko`를 사용하세요. 코드 업데이트 과정에서 기존 `.env`나 `data/`를 삭제·교체하지 마세요.

## 검증

- 전체 Python 테스트: `4985 passed, 3 skipped`.
- PDF·email highlight guard의 실패 회귀를 먼저 확인한 뒤 targeted test 통과.
- Python compile, 변경 JavaScript syntax, 정적 검사, `git diff --check` 통과.
- 실제 사용자 설치본 `127.0.0.1:7860`에서 기존 로그인·Codex 모델·채팅·Documents·Deep Research 보존 확인.
- headed browser에서 Vault Explorer와 Documents/Research UI를 열고 새 console error가 없는지 확인.
- 릴리스 검증 중 생성된 빈 테스트 문서는 삭제하고 기존 Documents count로 복원.

## 검증하지 않은 외부 환경

- 비식별 fixture가 없어 실제 HWP/HWPX 파싱은 수행하지 않았습니다.
- 실제 이메일 송수신, OAuth refresh, 유료 모델 호출은 수행하지 않았습니다.
- Docker CLI가 없는 릴리스 Mac에서는 Docker Compose를 재실행하지 않았습니다.
- Chromium 이외의 브라우저는 최종 시각 검증을 재실행하지 않았습니다.

## 데이터 및 릴리스 경계

- `.env`, `data/`, API key, OAuth token, session cookie, 사용자 Vault 원문은 Git과 릴리스에 포함되지 않습니다.
- 기존 `v0.1.9-ko`와 `v0.1.10-ko` 태그는 이동하지 않았습니다.
- 보고서와 Obsidian 노트는 사용자가 명시적으로 저장한 경우에만 생성됩니다.
