# v0.1.0-ko

Odysseus Korean Codex CLI workspace preview.

This release packages the Korean-friendly fork work so the same setup can be reused on another Mac or desktop without manually replaying the current local edits.

## Highlights

- Added a Korean UI overlay for the main chat, settings, memory, research, email, library, notes, tasks, and common modal text.
- Added Codex CLI subscription model discovery so Odysseus can use an existing ChatGPT/Codex CLI login path instead of requiring a separate OpenAI API key for basic chat usage.
- Added reasoning effort controls for Codex subscription models, including low, medium, high, and xhigh options where the backend supports them.
- Added Deep Research knowledge-source modes:
  - web research only
  - Obsidian-only research
  - hybrid web plus Obsidian research
- Added settings for an Obsidian vault root and research-modal selection for one or more subfolders.
- Improved Deep Research report generation so images referenced from local Obsidian notes can be embedded into the exported HTML report.
- Improved model picker density so long Codex subscription model labels fit better on smaller screens.
- Added a Korean end-to-end smoke test for the localized UI and model picker layout.

## For Korean Users

This fork is intended for users who want to run Odysseus with a Korean interface and an existing Codex CLI subscription workflow. The goal is to reduce the need for paid API keys or high-end local AI hardware while keeping Odysseus useful for chat, research, document organization, and Obsidian-based second-brain workflows.

## Install And Run

```bash
git clone https://github.com/flytothesky23/odysseus.git
cd odysseus
git checkout v0.1.0-ko
./start-macos.sh
```

Open:

```text
http://127.0.0.1:7860
```

## Known Gaps

- Docker runtime was not revalidated for this release candidate.
- Windows native install was not revalidated.
- Codex CLI subscription behavior depends on a valid local Codex/ChatGPT login session on the user's machine.
- Deep Research Obsidian reports can embed local images found from note references, but very large image sets may increase exported HTML size.
