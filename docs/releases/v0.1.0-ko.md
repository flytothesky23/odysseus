# v0.1.0-ko

Odysseus Korean Codex CLI workspace preview.

## Highlights

- Added a Korean UI overlay for the main chat, settings, memory, research, email, library, notes, tasks, and common modal text.
- Added Codex CLI subscription model discovery so Odysseus can use an existing ChatGPT/Codex CLI login path instead of requiring a separate OpenAI API key for basic chat usage.
- Added reasoning effort controls for Codex subscription models.
- Added Deep Research knowledge-source modes for web, Obsidian, local folders, and hybrid runs.
- Improved model picker density so long Codex subscription model labels fit better on smaller screens.
- Added a Korean end-to-end smoke test for the localized UI and model picker layout.

## Verification
