# v0.1.1-ko

Odysseus Korean fork patch release for safer file creation through agent tools.

This patch is for users who run the Korean Codex CLI/ChatGPT Subscription workflow and want the same local stability improvements on another Mac or desktop.

## Highlights

- Fixed `write_file` tool parsing when the model sends a JSON payload instead of the legacy plain-text format.
- Applied the same JSON payload handling to the filesystem tool execution path.
- Added regression coverage for JSON-based file writes while preserving workspace path confinement.

## Why This Matters

Some Codex-style tool calls naturally produce structured JSON such as:

```json
{
  "path": "note.md",
  "content": "..."
}
```

Before this patch, Odysseus could treat that whole JSON block as plain text, causing file creation to fail or target an invalid path. This release makes the agent file-writing path more tolerant without loosening workspace path restrictions.

## Install And Run

cd odysseus
git checkout v0.1.1-ko
