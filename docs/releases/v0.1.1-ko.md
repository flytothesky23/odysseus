# v0.1.1-ko

Odysseus Korean fork patch release for safer file creation through agent tools.

## Highlights

- Fixed `write_file` tool parsing when the model sends a JSON payload instead of the legacy plain-text format.
- Applied JSON payload handling to the filesystem tool execution path.
- Added regression coverage for JSON-based file writes while preserving workspace path confinement.

## Why This Matters

Some Codex-style tool calls naturally produce structured JSON. This release made the agent file-writing path more tolerant without loosening workspace path restrictions.
