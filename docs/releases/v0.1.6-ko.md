# v0.1.6-ko

This patch lets Deep Research choose a reasoning effort per report run.

## Highlights

- Adds a `추론` selector to the Deep Research settings panel.
- Supports `자동`, `낮음`, `보통`, `높음`, and `매우 높음`.
- Sends the selected value as `reasoning_effort` through `/api/research/start`.
- Applies the normalized value to every Deep Research LLM call.
- Preserves the setting in active jobs, library entries, result metadata, session JSON, and Markdown frontmatter.
