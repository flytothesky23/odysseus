# v0.1.14-ko

`v0.1.14-ko`는 `v0.1.13-ko`의 실제 본문 기반 한국어 웹검색을 유지하면서, 후속질문에서 끊어진 맥락을 복구하고 검증된 검색 결과를 하나의 진화형 Documents 아티팩트로 안전하게 누적하는 안정 릴리스입니다. 앱 자체의 upstream 버전은 `1.0.2`입니다.

## 핵심 변경

- “마지막 질문”, “위 맥락”, “답변이 질문과 다르다” 같은 한국어 보정 발화를 새 검색어로 오인하지 않고 마지막 실질 요청과 연결합니다.
- 같은 근거 follow-up은 저장된 fetched body와 stable source identity를 재사용하고, 최신·추가 근거가 필요한 경우에만 bounded delta retrieval을 수행합니다.
- 모델이 URL 인용과 숫자 인용을 함께 낸 경우에도 같은 검증 근거 링크를 한 번만 표시합니다.
- 검증된 복수 출처 웹 합성은 채팅별로 하나의 `web-knowledge` Documents 아티팩트를 생성하고, 후속 답변은 같은 문서의 새 버전으로 누적합니다.
- 아티팩트 frontmatter의 KST 갱신 시각과 source count를 중복 없이 갱신하고, GitHub repository/README의 논리적 source identity를 하나로 취급합니다.
- Documents 패널이 닫힌 상태에서 AI 문서가 도착해도 편집기를 다시 연결해 빈 화면이나 stale body overwrite가 발생하지 않게 합니다.
- AI 문서 diff가 미해결인 동안 autosave를 차단하고, 서버의 최신 version과 다른 수동 저장은 `409 stale_document_version`으로 거부합니다.
- Markdown 표 divider의 ASCII dash뿐 아니라 모델이 출력하는 Unicode dash도 안전한 실제 HTML 표로 렌더링합니다.
- Markdown은 표·링크·Mermaid `Preview`, HTML/SVG/XML은 sandbox iframe의 실제 `Run / Preview`를 유지합니다.

## 새 기기에 설치

```bash
git clone --branch v0.1.14-ko --depth 1 https://github.com/flytothesky23/odysseus.git
cd odysseus
```

Docker 설치는 다음과 같이 시작합니다.

```bash
cp .env.example .env
docker compose up -d --build
```

macOS·Windows native 설치와 GPU 설정은 [setup guide](../setup.md)를 따르세요.

## 기존 설치 업데이트

서비스를 종료하고 `.env`와 `data/`를 먼저 백업하세요. `data/app.db`와 `data/.app_key`는 반드시 같은 시점의 한 쌍이어야 합니다.

```bash
git status --short
git fetch origin --tags
git switch dev
git pull --ff-only origin dev
git rev-parse HEAD
git rev-list -n 1 v0.1.14-ko
```

마지막 두 커밋이 같아야 합니다. 태그에 고정하려면 별도 설치 폴더에서 `git switch --detach v0.1.14-ko`를 사용하세요. 코드 업데이트 과정에서 기존 `.env`나 `data/`를 삭제·교체하지 마세요.

## 검증

- 실제 7860의 기존 사용자 계정과 `gpt-5.6-luna` Codex OAuth에서 공식 OpenAI·GitHub 본문 조회, 한국어 비교 표, 주장별 클릭 가능한 인라인 인용을 확인했습니다.
- 같은 근거 follow-up은 신규 검색 없이 재사용했고, delta retrieval은 기존 근거를 유지하면서 새 공식 근거만 추가했습니다.
- 실제 검색 취소는 `Cancelled by user`로 종료됐고, 재시도는 새 공식 본문을 읽어 정상 완료했습니다.
- 생성된 웹 지식 아티팩트는 최초 생성 후 같은 문서의 버전으로 갱신됐으며 중복 인용·중복 frontmatter 필드는 0건이었습니다.
- 전체 Python 테스트: `5152 passed, 3 skipped`.
- 변경 Python compile, 변경 JavaScript syntax, 정적 회귀, `git diff --check`를 통과했습니다.
- 테스트 세션·메시지·Documents·기억·벡터 fixture를 제거하고 개인화 count와 암호화 복호화 실패 0을 재확인했습니다.

## 검증하지 않은 외부 환경

- 실제 이메일 송수신과 OAuth refresh는 수행하지 않았습니다.
- 사용자 Vault 원문과 HWP/HWPX 원본은 변경하지 않았습니다.
- Chromium 이외의 브라우저에서는 최종 headed E2E를 재실행하지 않았습니다.
- Docker Compose는 이 macOS 설치본의 최종 수락 경로가 아니므로 재실행하지 않았습니다.

## 데이터 및 릴리스 경계

- `.env`, `data/`, API key, OAuth token, session cookie, 사용자 질문·대화·검색 본문은 Git과 릴리스에 포함되지 않습니다.
- 웹 지식 Documents는 검증된 최종 합성이 있는 경우에만 생성·갱신되며, 임의 코드 fence나 실패한 검색을 정상 아티팩트로 저장하지 않습니다.
- 기존 `v0.1.9-ko`부터 `v0.1.13-ko`까지의 tag는 이동하거나 삭제하지 않습니다.
