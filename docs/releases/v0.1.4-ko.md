# v0.1.4-ko

Odysseus Korean fork patch release for managing Finder-added local knowledge folders in Deep Research.

## Highlights

- Added a compact local knowledge folder management list to the Deep Research modal.
- Added a `Delete` action for each Finder-added local knowledge root.
- Deleting a folder removes only the Odysseus knowledge-source setting.
- Actual folders and files on the Mac are never deleted by this action.
- Reused the owner-gated backend deletion route.

## Verification

- `node --check static/js/research/panel.js && node --check scripts/e2e-ko-smoke.cjs`
- Targeted owner-scope and knowledge-source pytest slice.
- `git diff --check`
- `ODYSSEUS_E2E_URL=http://127.0.0.1:7861 npm run e2e:ko`

## Known Gaps

- Full Python suite and Docker runtime were not rerun for this patch release.
- A manual click deleting a real user local root was not performed during release verification.
