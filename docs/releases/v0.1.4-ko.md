# v0.1.4-ko

Odysseus Korean fork patch release for managing Finder-added local knowledge folders in Deep Research.

This patch is for users who use local folders, JSON/YAML/CSV files, and Obsidian-adjacent project notes as private Deep Research context. Finder-added folders can now be removed from the Research modal without deleting files on disk.

## Highlights

- Added a compact local knowledge folder management list to the Deep Research modal.
- Added a `Delete` action for each Finder-added local knowledge root.
- Deleting a folder removes only the Odysseus knowledge-source setting.
- Actual folders and files on the Mac are never deleted by this action.
- Preserved unrelated selected knowledge folders after deleting one local root.
- Reused the existing owner-gated backend route:
  - `DELETE /api/research/knowledge/local-folders/{root_id}`
- Added backend route tests for local single-user deletion and auth-enabled admin protection.
- Extended Korean E2E smoke coverage so configured local folder rows must expose delete controls and avoid modal overflow.

## Why This Matters

Deep Research local sources are iterative. Users add folders while exploring a topic, then later need to remove stale project folders before running another report.

Previously, the UI made adding local folders easy but did not expose the matching remove action. That made the local knowledge source list accumulate old roots and reduced trust in which private files were being used. This patch makes the source list reversible and safer.

```bash
cd odysseus

./start-macos.sh
```

Open:

```text
http://127.0.0.1:7860
```

## Notes For Existing Installs

- Restart the Odysseus server after upgrading.
- Refresh the browser so the Research modal loads the updated JavaScript.
- In Deep Research, choose a source mode that uses local knowledge, then use the `Delete` button next to a Finder-added folder.
- The delete action removes Odysseus configuration only. It does not move, edit, or delete local files.
- Search API keys, ChatGPT/Codex login tokens, `.env` secrets, and private auth files remain local machine setup and are not included in the release.

## Known Gaps

- Full Python suite was not rerun for this patch release.
- Docker runtime was not revalidated for this patch release.
- E2E verifies the delete control and layout when local roots exist; targeted route tests verify the actual settings deletion path.
- A manual click deleting a real user local root was not performed during release verification to avoid changing the user's configured source list.
