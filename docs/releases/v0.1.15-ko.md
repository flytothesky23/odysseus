# v0.1.15-ko

`v0.1.15-ko`는 웹검색이 켜졌다는 이유만으로 대화 맥락을 버리거나 불필요한 검색을 실행하던 문제를 바로잡고, 한국어 요청을 대화·기억·선택 자료·검증된 웹 근거와 정확히 연결해 실제 Documents 아티팩트까지 완성하는 안정 릴리스입니다. 앱 자체의 upstream 버전은 `1.0.2`입니다.

## 핵심 변경

- 웹검색 토글을 사용 가능한 능력으로만 취급합니다. 최신·외부 사실 확인을 명시한 요청만 검색을 강제하며, 자기소개서·요약·문서 작성처럼 현재 맥락으로 답할 수 있는 요청은 불필요한 웹검색 없이 처리합니다.
- “멋진 자기소개 HTML” 같은 한국어 문서 의도를 직접 인식하고, 대화·AI 기억·선택된 Workspace 자료를 우선 사용합니다. 확인되지 않은 개인 정보는 꾸며내지 않고 편집 가능한 자리표시자로 남깁니다.
- 모델이 `create_document` 실행을 말로 약속한 경우 실제 도구가 성공하기 전에는 그 문장을 노출하지 않습니다. 누락되거나 실패한 문서 효과는 재시도하며, 내부 진단문과 미완성 HTML을 정상 결과처럼 표시하지 않습니다.
- 웹 근거와 HTML 생성이 함께 필요한 요청은 검색 계획 → 후보 발견 → 본문 조회 → 사용 가능한 근거 선택 → 한국어 합성·인용 검증 → Documents 생성 순서로 실행합니다.
- Markdown 직접 링크, 숫자 인용, reference-style 인용을 검증된 source identity에 맞춰 클릭 가능한 인라인 링크로 정규화합니다. 연속 숫자 인용은 서로 합치지 않고, 중복 footnote 정의는 제거합니다.
- 공식 웹 근거를 사용한 표는 파이프 문자 원문이 아니라 실제 HTML 표로 렌더링하고, HTML Documents는 격리된 `Run / Preview`에서 실제 화면으로 확인할 수 있습니다.
- 같은 근거 follow-up은 fetched body와 source identity를 재사용하며, 새로운 사실이 필요한 delta 질문만 추가 검색합니다. 검색 취소와 재시도 상태도 답변 완료 상태와 분리합니다.

## 새 기기에 설치

```bash
git clone --branch v0.1.15-ko --depth 1 https://github.com/flytothesky23/odysseus.git
cd odysseus
```

Docker 설치는 다음과 같이 시작합니다.

```bash
cp .env.example .env
docker compose up -d --build
```

macOS·Windows native 설치와 GPU 설정은 [setup guide](../setup.md)를 따르세요.

## 기존 설치 업데이트

서비스를 종료하고 `.env`와 `data/`를 먼저 백업하세요. `data/app.db`와 `data/.app_key`는 반드시 같은 시점의 한 쌍이어야 합니다.

```bash
git status --short
git fetch origin --tags
git switch dev
git pull --ff-only origin dev
git rev-parse HEAD
git rev-list -n 1 v0.1.15-ko
```

마지막 두 커밋이 같아야 합니다. 태그에 고정하려면 별도 설치 폴더에서 `git switch --detach v0.1.15-ko`를 사용하세요. 코드 업데이트 과정에서 기존 `.env`나 `data/`를 삭제·교체하지 마세요.

## 실제 수락 검증

- 실제 `/Users/flytothesky/Downloads/odysseus`의 7860, 기존 사용자 계정과 `gpt-5.6-luna` Codex OAuth에서 headed Chrome E2E를 수행했습니다.
- 웹검색 토글을 켠 자기소개 HTML 요청은 웹검색을 실행하지 않고 `create_document`를 완료했으며, 한국어 섹션과 편집 가능한 자리표시자를 실제 HTML 미리보기로 렌더링했습니다.
- 공식 OpenAI Codex 소개와 GitHub `openai/codex` README를 실제로 읽고, 공통 기능 두 가지를 한국어 표로 합성해 각 주장 뒤에 클릭 가능한 인라인 인용을 표시했습니다.
- 같은 공식 근거 follow-up은 신규 검색 없이 재사용했고, delta retrieval은 새 OpenAI 공식 자료 한 건만 추가해 같은 웹 지식 아티팩트의 다음 버전으로 누적했습니다.
- 검색 취소는 `Cancelled by user`로 종료되고 답변 완료로 위장하지 않았으며, 동일 요청 재시도는 공식 본문·한국어 표·인라인 인용까지 정상 완료했습니다.
- 빈 assistant 카드, raw `missing_citation`, 읽지 않은 후보 source 노출, 검색 완료와 답변 실패의 상태 모순은 수락 시나리오에서 0건이었습니다.
- 전체 Python 테스트: `5164 passed, 3 skipped`.
- 변경 Python compile, 관련 회귀 176건, `git diff --check`를 통과했습니다. 변경 JavaScript 파일은 없습니다.
- E2E 세션·메시지·Documents·기억·벡터 fixture를 정확한 ID로 제거하고 기존 개인화 count와 암호화 복호화 실패 0을 재확인했습니다.

## 검증하지 않은 외부 환경

- 실제 이메일 송수신과 OAuth refresh는 수행하지 않았습니다.
- 사용자 Vault 원문과 HWP/HWPX 원본은 변경하지 않았습니다.
- Chromium 이외의 브라우저에서는 최종 headed E2E를 재실행하지 않았습니다.
- Docker Compose는 이 macOS 설치본의 최종 수락 경로가 아니므로 재실행하지 않았습니다.

## 데이터 및 릴리스 경계

- `.env`, `data/`, API key, OAuth token, session cookie, 사용자 질문·대화·검색 본문은 Git과 릴리스에 포함되지 않습니다.
- 개인 HTML 아티팩트는 확인된 맥락 또는 명시적 자리표시자만 사용하고, 웹 지식 Documents는 실제로 읽고 인용한 근거와 연결된 최종 합성이 있을 때만 생성·갱신합니다.
- `v0.1.14-ko`와 그 이전 tag는 이동하거나 삭제하지 않습니다.
